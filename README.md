# Proyecto Redes I - Policlínico San Gabriel

## 📌 Datos Generales del Proyecto
- **Título:** Diseño de la infraestructura física y cableado estructurado de una red LAN para el Policlínico San Gabriel
- **Curso:** Redes de Comunicación I
- **Modalidad:** Grupal (5 integrantes)
- **Organización Elegida:** Policlínico y Centro Médico San Gabriel (52 dispositivos)
